# Портфолио Батархана — вайб-кодер

Сайт-портфолио на русском языке. Сделан по шаблону «3D Portfolio» с [motionsites.ai](https://motionsites.ai/?prompt=3d-jack-portfolio-hero).

Технологии: React, TypeScript, Vite, Tailwind CSS, Framer Motion, Lucide.

## Как запустить на своём компьютере

1. Открой терминал в этой папке.
2. Один раз установи библиотеки: `npm install`
3. Запусти сайт: `npm run dev`
4. Открой в браузере адрес из терминала (обычно http://localhost:5173).
   Пока сайт запущен, все правки в коде сразу видны в браузере.

Собрать готовую версию для публикации: `npm run build` (результат появится в папке `dist`).

## Где что менять

- **Все тексты, ссылки и картинки** — в файле `src/data.ts`.
- **Скриншоты проектов** — в папке `public/projects`.
- **3D-портрет на первом экране** — сейчас там временная картинка из шаблона (персонаж Jack).
  Положи свой 3D-аватар (PNG с прозрачным фоном) в папку `public` и поменяй `portrait` в `src/data.ts`
  (подсказка есть в комментарии рядом).
- **Бегущая лента с GIF** — список `marqueeImages` в `src/data.ts`. Сейчас там превью шаблонов
  с motionsites.ai, а не твои работы. Со временем замени их на свои.

## Из чего состоит сайт

- `src/sections/` — секции страницы: первый экран, бегущая лента, «Обо мне», услуги, проекты, контакты.
- `src/components/` — повторяющиеся детали: кнопки и анимации (появление, «магнит», проявление текста).
- `public/` — файлы, которые копируются на сайт как есть (картинки, иконка вкладки).

## Шрифт

В шаблоне используется шрифт Kanit, но в нём нет русских букв. Поэтому стоит похожий шрифт Geologica.

## Публикация

Файл `.github/workflows/deploy.yml` настраивает автопубликацию: после каждого `git push` в ветку `main`
GitHub сам собирает сайт и выкладывает его на GitHub Pages.
